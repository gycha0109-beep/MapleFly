# result_v1 — 첫 초파리 제어 실험 결과

## 실험 목적

Brain in a Jar v1을 실제 브라우저에서 실행해,
MaleCNS connectome 출력이 MapleFly 캐릭터를 실제로 움직이고 공격까지 발생시키는지 확인했다.

이번 결과의 핵심은 "초파리가 사냥을 잘했는가"가 아니라
**connectome → 행동 → 게임 상태 변화의 폐루프가 실제로 돌아갔는가**이다.

---

## 확인된 것

실제 실행 영상에서 다음 현상이 확인됐다.

- MaleCNS connectome이 정상적으로 로드됨
- FLY CONTROL 상태에서 사람 키 입력 없이 캐릭터가 움직임
- 좌우 이동이 발생함
- 점프가 반복적으로 발생함
- 공격 동작이 반복적으로 발생함
- 하단 버섯 M-03의 HP가 실제로 감소함
- 최종적으로 M-03이 KO되고 KILLS 1이 기록됨
- 상단 버섯 M-01 / M-02는 처치하지 못함
- 사다리 근처까지는 가지만 의미 있게 사다리를 이용해 상층으로 이동하지 못함

즉 **기술적인 연결 자체는 동작했다.**

---

## 가장 중요한 해석

M-03 처치는 **목표지향적인 사냥 성공으로 해석하면 안 된다.**

영상상 캐릭터는 버섯을 정확히 찾아가서
"공격 사거리 진입 → 3회 공격 → 처치" 같은 계획적인 행동을 한 것이 아니다.

오히려 관찰된 행동은 다음에 가깝다.

```text
움직인다
→ 자주 점프한다
→ 공격도 여기저기 휘두른다
→ 그 과정에서 공격 hitbox와 버섯이 우연히 겹친다
→ HP가 깎인다
→ 같은 일이 몇 번 더 겹쳐 KO가 발생한다
```

따라서 현재 단계의 표현은

> **"버섯을 사냥했다"보다는 "막 휘두르다 버섯이 몇 번 얻어걸려 죽었다"가 정확하다.**

한국식으로 표현하면 거의 **"소 뒷걸음질 치다 쥐 잡은 격"**에 가깝다.

---

## 왜 이런 일이 일어났나

### 1. 공격에는 목적성이 없다

현재 ATTACK은 arm-pull descending group의 activity가 threshold를 넘으면 발생한다.

초파리 뇌 안에 "버섯을 공격하라"는 목표나
"HP를 0으로 만들라"는 보상 함수는 없다.

따라서 공격이 발생했다는 사실과
버섯을 의도적으로 공격했다는 것은 전혀 다른 이야기다.

### 2. 점프가 매우 자주 발생한다

현재 DNp01은 JUMP에 연결되어 있다.

버섯이 가까워질수록 LPLC2 / LC4에 looming·threat 계열 입력이 커지고,
그 결과 escape 계열 출력이 자주 활성화되면서 점프가 반복된다.

즉 현재 캐릭터는 대상을 향해 침착하게 접근한다기보다
**가까운 물체에 반응해 자주 튀는 행동**을 보인다.

### 3. 다층 이동 개념이 없다

초파리에게는 현재 다음과 같은 고수준 정보가 없다.

```text
저 버섯은 2층에 있다
→ 2층에 가려면 사다리를 찾아야 한다
→ 사다리 앞에서 위로 올라가야 한다
→ 그 뒤 점프 갭을 건너야 한다
```

따라서 M-01 / M-02를 보더라도
"상층에 있는 목표로 가는 경로"를 계획할 구조가 없다.

## v1 결과 요약

### 시스템 수준

```text
PASS  실제 MaleCNS connectome 로드
PASS  connectome output → MapleFly action 연결
PASS  캐릭터 좌우 이동
PASS  점프 발생
PASS  공격 발생
PASS  공격 hitbox가 실제 몬스터 HP에 영향
PASS  KO / KILLS 상태 변화
```

### 행동 수준

```text
미확인/실패  목표지향적 버섯 추적
실패          안정적인 근접 후 의도적 공격
실패          사다리 탐색 및 등반
실패          상층 이동
실패          M-01 / M-02 접근 및 처치
관찰          반복 점프 / 불규칙 이동 / 무작위에 가까운 공격
우연적 결과   M-03 KO 1회
```

## 결론

v1에서 확인한 것은

> **"초파리가 메이플 사냥을 할 수 있다"가 아니다.**

확인한 것은

> **"실제 MaleCNS connectome을 MapleFly와 폐루프로 연결했고,
> 그 신경 출력이 실제 게임 행동과 HP/KO 상태 변화까지 만들어낸다."**

이다.

M-03 처치는 흥미로운 결과지만,
현재 증거만으로는 목적지향적 행동이라고 부를 수 없다.

오히려 v1의 정직한 baseline은 다음 문장이 가장 정확하다.

> **초파리는 아직 버섯을 사냥한 것이 아니라, 막 돌아다니고 휘두르다가 버섯 하나를 우연히 잡았다.**

이 상태를 기준점으로 두고,
다음 버전부터 센서 인코딩이나 readout을 바꿀 때
"우연보다 나아졌는가"를 정량적으로 비교해야 한다.

## 다음 실험에서 기록할 지표

다음 버전부터는 최소한 아래 값을 자동 기록한다.

- 총 이동 거리
- LEFT / RIGHT 결정 횟수
- JUMP 횟수
- ATTACK 횟수
- 실제 HIT 횟수
- 공격 적중률 = HIT / ATTACK
- KILL 수
- 사다리 접촉 횟수
- 사다리 등반 성공 횟수
- 상층 진입 횟수
- 각 버섯까지의 최소 거리
- IDLE 비율

이 값들이 있어야
"그냥 휘두르다 얻어걸린 것"과 "실제로 행동이 개선된 것"을 구분할 수 있다.
