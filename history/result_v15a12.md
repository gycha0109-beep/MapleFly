## Interpretation

The result supports the narrower claim needed for the next phase:

> Frozen MaleCNS DN temporal history contains sufficient information, under the
> preregistered FULL48 probe family, to predict which of DRINK or WAIT has higher
> trainer-computed counterfactual return.

This is stronger than merely showing a coarse injury-burden correlation because the
authoritative target was generated by an explicit action-outcome evaluator.

It still does **not** show that a fly policy learned DRINK/WAIT from reward. v15A12 used
a supervised scientific probe over counterfactual targets.

## v15B authorization

v15A12 satisfies the preregistered prerequisite for a new **reward-only v15B
DRINK/WAIT learning experiment**.

v15B may now be preregistered, subject to:

- exact frozen v15A12 representation,
- HP-independent decision/taste opportunity,
- policy input restricted to DN features (plus its own prior POTION motor history if
  explicitly preregistered),
- trainer supplies only realized reward/outcome for the action actually chosen,
- no HP, impact count, DeltaG, optimal action, or counterfactual label enters policy
  training,
- deployment requires a separate holdout gate.

No v15A12 classifier is deployed as runtime POTION policy.

Existing MOVE v7, ATTACK v10F, JUMP v11H2, and v14C remain unchanged.
